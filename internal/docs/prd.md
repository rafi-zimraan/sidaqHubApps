# Product Requirements Document — SidaqHub

## 1. Overview
SidaqHub adalah aplikasi mobile jejaring sosial untuk komunitas Huffadz Indonesia. Aplikasi ini memungkinkan pengguna berbagi progres hafalan, bergabung dalam halaqah, dan berjejaring dengan sesama penghafal Al-Quran.

## 2. User Stories

### 2.1 Authentication
- US-01: Pengguna dapat mendaftar dengan email dan password
- US-02: Pengguna dapat login ke akun yang sudah ada
- US-03: Pengguna dapat mengatur profil setelah registrasi

### 2.2 Feed
- US-04: Pengguna dapat melihat feed postingan
- US-05: Pengguna dapat membuat postingan (teks, ayat, tilawah)
- US-06: Pengguna dapat like dan komentar postingan

### 2.3 Halaqah
- US-07: Pengguna dapat membuat halaqah online/offline
- US-08: Pengguna dapat bergabung dengan halaqah
- US-09: Pengguna dapat melihat jadwal halaqah

### 2.4 Profile
- US-10: Pengguna dapat melihat profil sendiri
- US-11: Pengguna dapat mengedit profil lengkap
- US-12: Pengguna dapat melihat progres hafalan (juz)

## 3. Non-Functional Requirements
- NFR-01: Waktu loading < 2 detik
- NFR-02: Support Android & iOS
- NFR-03: Dark mode support
- NFR-04: Aksesibilitas untuk pengguna dengan kebutuhan khusus

## 4. Constraints
- Saat ini tanpa backend (menggunakan mock data)
- Menggunakan Expo SDK 54
