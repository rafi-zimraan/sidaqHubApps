# Blueprint — SidaqHub

## Vision
Membangun ekosistem digital yang menghubungkan, memberdayakan, dan menginspirasi komunitas Huffadz (penghafal Al-Quran) di Indonesia.

## Mission
1. Menyediakan platform jejaring sosial khusus penghafal Al-Quran
2. Memfasilitasi halaqah (kelompok belajar) online & offline
3. Memotivasi progres hafalan melalui sistem badge Juz
4. Menghubungkan santri, ustadz, dan Huffadz dewasa

## Core Features
- **Feed** — posting ayat, teks, atau tilawah (audio)
- **Halaqah** — buat/ikuti kelompok belajar dengan jadwal
- **Jejaring** — follow, sambung sesama Huffadz
- **Badge Juz** — sistem penghargaan progres hafalan
- **Notifikasi** — real-time activity updates

## Target Users
- Santri Huffadz (aktif menghafal)
- Ustadz/Musyrif (pengajar & pembimbing)
- Huffadz Dewasa (penghafal Al-Quran dewasa)

## Tech Foundation
- React Native (Expo) — mobile cross-platform
- Apollo Client v4 — GraphQL integration
- Mock data layer — pengembangan tanpa backend
