# Branding — SidaqHub

## Brand Identity

### Name
**SidaqHub** — dari "Sidiq" (jujur/benar) + "Hub" (pusat/jejaring)

### Tagline
"Jejaring Huffadz Indonesia"
"Hubungkan, Inspirasi, Berkah"

### Logo
- Icon: kombinasi huruf Arab dan Al-Quran
- Warna utama: Teal (#1A5C6B) + Gold (#B8860B)
- Gaya: Modern Islamic, clean, professional

### Color Palette
| Name | Hex | Usage |
|------|-----|-------|
| Primary | #1A5C6B | Brand utama |
| Gold | #B8860B | Accent, badge |
| Dark | #0A2E3A | Header gradasi |
| White | #FFFFFF | Background utama |
| Light BG | #F4F5F7 | Background screen |

### Typography
- **Logo**: Poppins Bold
- **UI**: Poppins (400-700)
- **Arabic**: Amiri

### Voice & Tone
- **Ramah, Islami, Profesional**
- Bahasa Indonesia (utama), English (future)
- Islamic greetings (Assalamu'alaikum, Bismillah)
- Tidak ada slang berlebihan
