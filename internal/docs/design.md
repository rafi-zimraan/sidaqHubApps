# Design — SidaqHub

## Design Principles
1. **Islamic Aesthetic** — nuansa Islami modern, tidak kaku
2. **Clarity** — tipografi jelas, hierarki visual kuat
3. **Consistency** — komponen reusable, spacing konsisten
4. **Accessibility** — kontras cukup, touch target ≥ 44px
5. **Performance** — animasi ringan, render efisien
